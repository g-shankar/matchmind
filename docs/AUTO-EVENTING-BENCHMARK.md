# Synthetic tracking-to-event benchmark: results

> **Detected from synthetic tracking, not video.** Circular by construction: the tracking is rendered from the same simulated events used as ground truth, so detector and truth share the simulator's assumptions. Synthetic data only; not real tracking and not video.

Generated by `matchmind-autoevent benchmark`. Every number below comes from that run.

## Split design

Every threshold in detect.py was set while looking only at the tuning split (the five published matches, seeds 100-104). The held-out seeds were first run after the thresholds were frozen and were never used to change them.

Thresholds set on the tuning split: `CONTROL_RADIUS_M`, `CONTROL_REL_SPEED_MPS`, `KICK_SPEED_MPS`, `REST_SPEED_MPS`, `SPEED_FIT_S`, `LOOSE_S`, `SHOT_RANGE_M`, `SHOT_MIN_SPEED_MPS`, `SHOT_AIM_HALF_WIDTH_M`, `PRESSURE_MIN_S`, `SETTLED_S`, `RECOVERY_AFTER_SHOT_S`.
